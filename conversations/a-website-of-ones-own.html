How it is made

Made with Claude

Claude, an AI assistant, writes the code. Every decision stays with the owner, and the site lives in their own GitHub account, where each change is saved and can be undone.

Questions about AI, GitHub and ownership

Does the work pass to the AI? No. Words, pictures and pages stay in the owner’s GitHub account. Anthropic’s terms assign to the user whatever rights it might have in what Claude writes, and GitHub keeps a record of every change.

Why GitHub and plain pages? Plain pages load fast, last for years and carry no monthly platform fee. GitHub saves every version and publishes the site at no cost.

Does it have to be Claude? Claude is the one used and taught here. Another assistant, such as ChatGPT, can serve too.

Does AI take the craft away? It puts the craft within reach of people who could not have reached it alone, and gives the hours that went to code back to the work itself.
